# 快递站管理系统 · 使用教程

> 本文档面向**快递驿站一线操作员、业务用户体验人员及课程答辩演示者**，介绍如何登录已搭建好的「快递站管理系统」并完成从到车签收、入库上架、超期计费、扫码取件到异常件赔付闭环的全部日常工作。
>
> **系统访问地址**：`http://localhost:8088/`

---

| 登录账号 | 默认密码 | 身份与所属租户 | 登录后看到的界面与数据 |
| :--- | :--- | :--- | :--- |
| **`station00`** | `123456` | 总部驿站主管（独立租户 `快递站总部 station_hq`，角色 `ROLE_TENANT_ADMIN`） | 仅可看到「分站与授权」与「应用工作区」，在工作区可见 **全部 4 个快递站菜单**，并能给 `station01` 分站/角色精细勾选分发具体菜单；完全隔离 `admin`/`user` 及根系统 |
| **`station01`** | `123456` | 东区校园快递驿站操作员（下属分站 `station_east`，角色 `ROLE_EAST_COUNTER`） | 仅能看到总部主管勾选开放的 **「包裹入库与取件」** 和 **「问题件处理单」** 两个菜单（隐藏「货架区位档案」与「快递车批次签收」），且仅可见东区自己的 2 件包裹 |
| **`user`** | `123456` | 根租户示例业务用户（`rbac_tenant_root`） | 直接进入「应用工作区」，操作平台根演示数据（全部 4 个业务菜单，与 `station00` / `station01` 完全隔离） |
| **`admin`** | `123456` | 平台 IT 管理员（`rbac_tenant_root`） | 负责接收业务需求进行建表/设计菜单并分发应用包，必要时可介入调整下属分站或角色的菜单授权（兜底分发） |

> **安全提示**：登录后点击页面右上角用户名下拉菜单，选择 **「修改个人密码」** 即可自助更改自己的登录密码。

## 二、登录工作区与界面导航

1. 使用 `station00`（或 `user`）进入 **「应用工作区 -> 快递站管理系统」**，左侧默认展开全部 **4 个业务模块**：
   - **货架区位档案**
   - **快递车批次签收**
   - **包裹入库与取件**（日常最高频）
   - **问题件处理单**
2. 使用已被 `station00` 按菜单裁剪过的 **`station01`** 登录后，左侧仅显示被明确勾选开放的 **2 个业务菜单**（**「包裹入库与取件」** 和 **「问题件处理单」**），而 **「货架区位档案」** 与 **「快递车批次签收」** 被隐藏且禁止通过链接强行打开；但分站员在入库表单选用 `存放货架`（外键参照）时依然可正常下拉选择 `东区-1号智能架`。

## 三、日常业务全流程操作指南

### 场景 1：管理驿站货架区位（`货架区位档案`）

1. 点击左侧 **「货架区位档案」**，可以看到当前驿站配置的所有货架（如总部的 `A区-小件1号架`、`B区-中件2号架`、`C区-大件地堆区`；或东区驿站的 `东区-1号智能架`）。
2. **新增货架**：点 **「+ 新增」**，填写：
   - `货架编码名称`（如 `D区-冷链1号柜`）
   - `所属分区`（选择 `D区-生鲜冷链柜`）
   - `容量上限(件)`、`负责理货员`、`货架状态`
   - 点击 **「保存」** 即可完成录入，不同驿站（租户）建相同名字的货架也不会互相冲突。
3. **视图与导出**：右上角支持「表格 / 卡片」模式切换，点击 **「导出表格」** 可直接下载 Excel 兼容的 `.csv` 盘点台账。

---

### 场景 2：快递车到站批量签收（`快递车批次签收`）

当快递公司送货车抵达驿站时，先登记整车签收批次及随车验视明细：

1. 点击左侧 **「快递车批次签收」**，点 **「+ 新增」**。
2. 填写主表信息：
   - `签收批次号`：**不用填**（保存后会自动生成如 `CAR-20261125001` 的流水批次号）。
   - 选择 `快递品牌`（如顺丰速运）、填写 `派送司机/快递员`、`到站时间`、`随车件数`。
3. 在弹出窗口下方的 **「随车包裹明细」** 页签中，点击 **「+ 添加明细行」**：
   - 输入每一件快件的 `随车运单号`；
   - 若外箱破损则打开 `包装破损` 开关，并在 `验视备注` 记录情况；
   - 支持点明细行上的 **「详情编辑」** 弹出大表单细看，或点 **「保存」** 一并提交整张主子表。
4. 现场清点核对完成后，在列表该行点击 **「完成到站清点」**，批次状态会从 `待清点` 流转为 `已清点入库`。

---

### 场景 3：包裹扫码入库、上架通知与超期计费（`包裹入库与取件`）

这是驿站日常最核心的操作页面。

#### 3.1 新包裹入库登记
1. 点击左侧 **「包裹入库与取件」** → 点 **「+ 新增」**。
2. 按提示录入包裹信息：
   - `入库流水号`：留空自动按规则生成（`INB-日期+4位流水`）。
   - `快递运单号`：输入快递单号（平台自动校验不少于 6 位且同一驿站不可重复录入）。
   - `快递品牌` / `快件规格`：直接从字典下拉选取（列表显示为彩色标签）。
   - `收件人姓名` / `收件人手机`：系统强制校验 **11 位标准手机号**，输错位数保存时会给出明确提示。
   - `取件码`：输入分配的取件码（如 `1-2-108`）。
   - `存放货架`：输入关键词模糊搜索并选择目标货架（例如 `A区-小件1号架`）。
   - 点击 **「保存」**（如要连续扫描入库，可点 **「保存并继续新增」**，弹窗不关闭直接录下一件！）。

#### 3.2 查看详情与自动关联带出
- 点击任意包裹行右侧的 **「详情」**，页面右侧会滑出 **单据详情抽屉**：
  - 自动展示包裹的完整基础信息（包括列表为保持简洁而收起的 **「货架理货员」** 字段——系统会根据所选货架自动关联带出！）；
  - 底部「系统留痕」区块记录了创建人、创建/更新时间与乐观锁版本号；
  - 如需改动，可直接点击抽屉底部的 **「编辑此记录」**。

#### 3.3 包裹上架、取件核验与超期保管费核算
页面针对不同状态的包裹智能启用对应流转按钮（不合流程的按钮自动置灰不可误点）：

1. **确认上架待取**：对 `待上架` 状态的包裹（如演示数据中的 `1-1-008`），放到货架后点击 **「确认上架待取」**，状态立刻变为 **`待取件`**。
2. **超期滞留自动计费**：
   - 系统配置了规则：**免费保管 3 天，超出第 3 天按 1 元/天计收保管费**；
   - 以演示包裹 `3-0-021`（滞留天数 `5` 天）为例，列表直接显示 `超期保管费(元)` = `2`；
   - 点击该行的 **「核算超期费」** 按钮（自定义 Groovy 脚本），系统会重新核算并弹出提示：`取件码 [3-0-021] 滞留 5 天，超期保管费：￥2.0`。
3. **核验取件出库**：
   - 顾客到站提供取件码（如 `2-3-105`）或手机号后 4 位，操作员在顶部搜索区输入关键词点 **「查询」** 迅速定位包裹；
   - 核验无误后点击该行的 **「核验取件出库」**，包裹状态流转为 **`已取走`**。

### 场景 4：异常件标记与破损工单闭环（`问题件处理单`）

1. 如果某包裹出现破损、联系不上收件人或拒收，先在「包裹入库与取件」中点击 **「转为异常件」**（状态变为红色 `异常滞留`）；或直接将客户拒收件点 **「退回寄件人」** 标记为 `已退回`。
2. 切换到左侧 **「问题件处理单」** → 点 **「+ 新增」**：
   - `关联包裹`：搜索选定对应的异常包裹（如 `INB-202611250003`）。
   - `紧急程度`：选 `特急` / `加急` / `普通`。
   - `异常描述`：说明破损或滞留原因。
   - `破损拍照凭证`：点击选择文件上传现场照片或面单凭证（上传后在详情/列表中支持直接点击下载查看）。
   - 保存后，工单自动生成 `WT-...` 单号，初始状态为 `待处理`。
3. **处理闭环**：
   - 操作员/站长点 **「受理核查」** → 状态变为 **`核查中`**；
   - 协商定责后点「编辑」填写 `处理结论`（如 `合格` / `待复检` / `不合格`），再点 **「确认办结」**，工单变为 **`已办结`**。

## 四、三级权限边界与多租户隔离演示指南（答辩重点）

若需要现场展示平台的 **分级授权与严格数据隔离边界**：

1. **分站运营端 (`station01` / `123456`，东区校园快递驿站)**：
   - 登录后只有运行态页面，且按分站/角色菜单白名单仅可见 **「包裹入库与取件」** 与 **「问题件处理单」**（直接访问 `#/m/exp_shelf` 会触发后端权限拦截并弹出拒绝提示）；
   - 列表仅可见东区驿站自己的 **2 条包裹**（`JD0011223344`、`SF9900112233`），新增包裹时仍可在 `存放货架` 下拉框选用 `东区-1号智能架`；**看不到总部直属包裹，也看不到根租户演示包裹**。
2. **总部主管端 (`station00` / `123456`，快递站总部)**：
   - 登录后顶部仅显示 **「分站与授权 / 应用工作区」**，**完全看不到平台根系统菜单（应用建模、字典、编码、清理后台）**；
   - 在 **「分站与授权」** 中，可点击分站的 **「应用与菜单授权」** 精细增减分站菜单勾选，或切换到 **「角色与操作权限」** 页签新建/编辑自定义岗位角色（如 `ROLE_EAST_COUNTER`）勾选具体菜单与按钮；租户与账号清单严格隔离 `admin` 与 `user`；
   - 进入「应用工作区 -> 包裹入库与取件」，保留总部完整的 4 个菜单并可监管总部自营包裹（`YTO7788990011`）及下属东区驿站的 2 件包裹，同样彻底隔离根租户数据。
3. **平台 IT 管理员端 (`admin` / `123456`) 与根演示端 (`user` / `123456`)**：
   - 使用 `admin` 可负责应用建模、字典编码规则调整与菜单设计，并可在必要时进入「租户与分站授权」直接兜底调整各总部或分站的菜单勾选；
   - 使用 `user` 打开「包裹入库与取件」，可见平台根租户的 **4 条独立包裹**（`INB-...0001` ~ `0004`），与 `station00` / `station01` 互不可见、互不冲突。
